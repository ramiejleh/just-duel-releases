# Just Duel! releases

Builds of a private fan-made dueling game, for friends. The source is not published here.

**Install:** open the latest release under *Releases* and download:
- **Windows:** `Just Duel! Setup <version>.exe` (installer), or the `.zip` to run without installing.
  The builds aren't signed: if Windows says it "protected your PC", choose *More info*, then *Run anyway*.
- **macOS (Apple silicon):** the `.dmg`. The first time, right-click the app and choose *Open*.

**Updates:** once installed, the game checks here for new versions and offers them on its title screen.
